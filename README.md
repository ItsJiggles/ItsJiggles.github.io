## 🧩 Project vibe

This site is built with:

- HTML5 🏗️
- CSS3 🎨
- JavaScript ⚙️

It has a colorful, playful style with bright gradients, punchy buttons, and a friendly retro feel 😎

## 🚀 Run it locally

Open the site directly in a browser or serve it with a tiny local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 📁 Main files

- `index.html` — the main landing page 🏠
